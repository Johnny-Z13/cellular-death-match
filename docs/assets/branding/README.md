# Z13 studio ident assets

`public/branding/` holds the Z13 Labs boot ident used by `src/ui/studioIdent.ts`.
Both files were copied without modification on 2026-10-14 from
`Projects/Websites/z13labs-website/public/branding/`. Those files were in turn
copied from `Projects/Art/kaleidoscope/playtest/assets/` and are recorded in
`z13labs-website/docs/studio-intro.md`.

Johnny asked for the ident at the start of Z13 games on 2026-10-14. The ident
sound is AI-generated audio (ElevenLabs). It is not part of this repository's
`public/audio/generated/manifest.json`, because it was generated for the
studio rather than for this game.

The browser favicon `public/branding/z13-diamond-icon.svg` embeds the unchanged
Z13 mark with a yellow diamond and dark background. It was approved for the
website on 2026-10-15. The game now uses the cellular Dr. E icons described in
[dr-e-icons.md](dr-e-icons.md); Z13 remains the studio ident.
